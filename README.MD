# Projeto: Meu Primeiro Card Front-end 🚀

Este é um projeto desenvolvido como parte dos meus estudos iniciais em **Engenharia de Software**. O objetivo foi aplicar conceitos fundamentais de desenvolvimento web, focando na organização de arquivos e estruturação de código.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação do conteúdo.
- **CSS3**: Estilização e layout (localizado na pasta `/css`).
- **JavaScript**: Lógica de interação (localizado na pasta `/js`).

## 📁 Organização do Projeto
Para garantir a escalabilidade e manutenção do código, o projeto foi organizado da seguinte forma:
- `index.html`: Arquivo principal.
- `/css`: Folhas de estilo.
- `/js`: Scripts de comportamento.
- `/assets`: Imagens e recursos visuais.
